# Examples

## Echo

Echoes back the input:

``` sh
go run ./echo
open http://localhost:8080/ui/
```

## Adder

Simply a + b MCP tool:

``` sh
go run ./adder
open http://localhost:8080/ui/
```

## Storybook

Contains about every widget supported by the library:

``` sh
go run ./storybook
open http://localhost:8080/ui/
```
